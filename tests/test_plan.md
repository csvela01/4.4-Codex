# Checklist Breve de Pruebas y Entrega

## 1) Checklist de pruebas mínimas
- [ ] El programa corre en terminal.
- [ ] Se validó al menos un caso exitoso.
- [ ] Se validó al menos un caso con error de entrada.
- [ ] La salida coincide con lo esperado en la propuesta.

## 2) Checklist de documentación
- [ ] `docs/propuesta.md` está completo.
- [ ] `docs/caso_de_uso.md` está completo.
- [ ] `docs/plan_de_pruebas.md` tiene casos registrados.
- [ ] El alcance está claramente delimitado.

## 3) Checklist de ejecución
- [ ] `scripts/run.sh` existe y tiene instrucciones útiles.
- [ ] Existe `src/main.<ext>` acorde al lenguaje elegido.
- [ ] No se usan frameworks ni dependencias complejas.
- [ ] No se usan APIs externas ni servicios de nube.

## 4) Checklist de entrega final
- [ ] Repositorio ordenado y sin archivos basura.
- [ ] Entrega subida a GitHub Classroom.
- [ ] Proyecto pequeño, viable y bien justificado.
- [ ] Prototipo mínimo opcional alineado con la documentación.
